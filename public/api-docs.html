POST /api/ask
Ask Question API with Video Pause Timestamp (Slide 3 & 4)
Request Headers
Content-Type: application/json
Body Parameters
Field Type Required Description
query string Yes The student's doubt or question regarding what was taught so far.
pauseSeconds number No (Default: 0) The exact video playback pause time in elapsed seconds (e.g. 150 for 02:30).
mode string No (Default: "temporal") "temporal" (enables Horizon Masking guardrail) or "naive" (unrestricted baseline).
