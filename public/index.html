The Non-Linearity Requirement

Consider a multi-layer feedforward network where each layer computes \( h_1 = W_1 x + b_1 \) and \( h_2 = W_2 h_1 + b_2 \). Composing these gives: \( h_2 = W_2 (W_1 x + b_1) + b_2 = (W_2 W_1) x + (W_2 b_1 + b_2) \).

Since the product of two matrices \( W_2 W_1 \) is simply another matrix \( W' \), a multi-layer linear network has no more representational capacity than a single-layer perceptron. It cannot compute non-linear decision boundaries or solve problems such as XOR.

By inserting a fixed, non-linear activation function \( \sigma(\cdot) \) between layers, \( h = \sigma(W x + b) \), the network gains the ability to deform coordinate space and approximate arbitrary continuous functions (Universal Approximation Theorem).
