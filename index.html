The Non-Linearity Requirement

Consider a multi-layer feedforward network where each layer computes \( h_1 = W_1 x + b_1 \) and \( h_2 = W_2 h_1 + b_2 \). Composing these gives: \( h_2 = W_2 (W_1 x + b_1) + b_2 = (W_2 W_1) x + (W_2 b_1 + b_2) \).

Since the product of two matrices \( W_2 W_1 \) is simply another matrix \( W' \), a multi-layer linear network has no more representational capacity than a single-layer perceptron. It cannot compute non-linear decision boundaries or solve problems such as XOR.

By inserting a fixed, non-linear activation function \( \sigma(\cdot) \) between layers, \( h = \sigma(W x + b) \), the network gains the ability to deform coordinate space and approximate arbitrary continuous functions (Universal Approximation Theorem).

⚡ 2-Minute Recap at 02:30

You are currently in Module 2: Activation Functions.

  • The pre-activation sum is \( z = \sum w_i x_i + b \).
  • Pure linear combinations collapse into a single matrix multiplication regardless of layer depth.
  • Activation functions (Sigmoid, ReLU) break linearity and unlock representational capacity for non-linear boundaries (XOR).

Technical Architecture & Temporal RAG Innovation

1. The Fatal AI Gap & Innovation

Standard AI chatbots in e-learning platforms search the entire course transcript indiscriminately. When a student pauses early in a lecture and asks a question, standard RAG retrieves future explanations, leaking future concepts, equations, and solutions.

The Mathematical Masking Rule:
Search Space = { Chunk_i | StartTime(Chunk_i) ≤ CurrentPauseTime }
Masked Space = { Chunk_j | StartTime(Chunk_j) > CurrentPauseTime } (Filtered BEFORE Vector Search)
